# Reference material sources

This library retains useful material from the project's existing asset collection. The catalog keeps original IDs and relevant source/usage metadata. New PNGs are faithful exports of existing vector or presentation material; they are not newly generated target-project architecture figures.

## Third-party icons

- **Tabler Icons**, originally imported from `@tabler/icons` version 3.44.0. Source: https://github.com/tabler/tabler-icons. License: [MIT notice](licenses/tabler-MIT.txt). The existing normalized vector variants and their previews are retained with this attribution.
- **Lucide**, originally imported from `lucide-static` version 1.16.0. Source: https://github.com/lucide-icons/lucide. License and upstream notices: [Lucide license text](licenses/lucide-ISC.txt). Original import/version information remains in the relevant catalog entries.

## Project material

The layout/style boards, generated vector primitives, and high-level concept presentation are inherited project material. They are retained from [paper-framework-figure-studio-pro](https://github.com/c-narcissus/paper-framework-figure-studio-pro) (by c-narcissus, MIT-0), from which C2A derives; see the [Acknowledgements](../README.md#致谢) for the full provenance chain. The project license is [MIT-0](../LICENSE); individual catalog entries retain any more specific source or usage information supplied with the original assets.

The abstracted mechanism motifs retain their original visual-reuse terms in `provenance.license`. They are generic visual/layout references, not evidence about the new code project. Do not transfer source-paper claims, metrics, datasets, labels, or literal figure reproductions. Historical titles and reference IDs are provenance; the corresponding original paper images are not bundled and must not be offered as available local attachments.

When a selected reference is copied into a run, include its source and applicable usage information in the candidate's reference guide. Do not assume that the root license replaces the third-party notices or per-asset terms.
